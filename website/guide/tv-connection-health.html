Автопроверка активного соединения ТВ — кандидат

На принятой владельцем rc.133 подготовлен отдельный stacked PR/feature/tv-connection-health. Предыдущий updater не объявляется автоматически merged. Новая функциональность требует полного CI и приёмки на физическом Phone/TV.

Поведение

Когда активный сервис переходит в Connected и TV видим: сразу стартует один bounded URL test через уже запущенное ядро (существующий testConnectionReport/Libcore.urlTest, timeout 3 секунды, настроенный test URL). На главном экране в карточке перед YouTube: проверяем / URL доступен и задержка / человеческая причина + диагностический NET-код. Профиль и текущие скорости компактны; время проверки видно, полные счётчики/подробности/повтор — по OK.

Состояние Connected — лишь ядро запущено. Успех URL проверяет один endpoint/маршрут, не все интернет-сервисы или видео. DNS/transport/auth/TLS выполняются как необходимые части запроса, но не заявляются отдельно измеренными тестами. TCP/ping не доказывают Hysteria UDP или REALITY auth; heavy speed tests/all-profile tests автоматически не запускаются.

Один тест на connection/profile/network epoch, без reconnect и циклических retries; смена сети/профиля отменяет старый результат. Трафик не создаёт повторов. Выход в фон отменяет UI job; незавершённая проверка может продолжиться один раз при возврате. Завершённый результат имеет возраст, не вечный зелёный статус. Binder/native вызов может завершиться в своём 3-секундном timeout после отмены UI. Автоматическая ошибка не вызывает modal и не меняет фокус/выбранный профиль. Явный повтор доступен из статуса; постоянный health/failover — отдельный R13 scope.

Приёмка

Connect → без нажатия «тест» виден результат; стабильность focus и расположение до YouTube. REALITY/TLS/DNS/timeout/UDP-block scenarios на разрешённом сервере; no false success только по нулевому/ненулевому трафику. Отключиться/сменить профиль/сеть во время теста: старый успех не относится к новому. Return from YouTube/background: нет авто-reconnect или modal. Проверить 720p/1080p, font scale и отсутствие обрезанного первичного результата. Offline CI/session tests не равны real VPN throughput certification.

Source-linked граф и бюджеты действий поддерживаются в CI. Изменения дальнейшей группировки меню сначала оцениваются по графу, а не скрывают старые функции.
