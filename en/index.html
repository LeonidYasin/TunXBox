Installation & updates

Download the APK matching your device and allow installation from that source. Keep the same package and signing identity for in-place updates. Back up your configuration before any reinstall.

Signing and update guide →

TunXBox is a client, not a VPN subscription service. You supply your own server or compatible configuration. It is not currently listed in the main F-Droid repository.

What TunXBox adds

Remote-first TV interface

Use D-pad navigation on Android TV while keeping a phone interface in the same app.

Profiles and local transfer

Organise connections and exchange configurations over your local network. Do not post private subscription links or raw configurations in public issues.

Open development

Read the source, review known limitations and help test real devices. Protocol and performance issues remain documented rather than hidden.
