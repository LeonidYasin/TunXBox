# TunX 1.7.0

Android-клиент для телевизора и смартфона на базе NekoBox/SagerNet и sing-box. Для подключения нужны собственные серверы или совместимая конфигурация; приложение не продаёт VPN-подписки.

## Изменения относительно 1.6.0

Цикл 1.7.0 сфокусирован на продолжении функциональности и стабильности отдельными согласованными PR. Конкретный scope фиксируется по мере готовности и приёмки каждого изменения; этот список заполняется только фактическими принятыми изменениями. Базовые границы сохраняются: никакой silent profile/VPN-подмены, автозагрузка исполняемых core в APK, отключение TLS/REALITY-проверок или копирование неподдерживаемого транспорта.

На этапе подготовки этот файл — материал для предстоящего release: подтверждённая публикация стабильного 1.7.0 определяется GitHub Releases и проверенными артефактами точного release SHA, а не существованием этого файла.

## Установка и обновление

Выберите ARM64, ARM32 или universal APK по фактическому `apk-manifest.json`. Package — `com.tunxbox.app`, постоянная подпись сохраняется; для версии 1.7.0 ожидаемый stable versionCode — **49 999 999**, выше RC серии 49 и stable 1.6.0 (48 999 999). Установка поверх приложения с тем же package и сертификатом не требует удаления; подпись не отключается.

## Проверки и границы

Наполняется после фактического CI и приёмки конкретных изменений цикла. Открытые мониторинговые reports #6/#10, F-Droid recipe disabled и связанные лицензионные/build-server gates остаются в силе по [handoff](../agent-handoff.md) и `fdroid/READINESS.md`.
