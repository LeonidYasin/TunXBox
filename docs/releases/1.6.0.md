# TunXBox 1.6.0

Android-клиент для телевизора и смартфона на базе NekoBox/SagerNet и sing-box. Для подключения нужны собственные серверы или совместимая конфигурация; приложение не продаёт VPN-подписки.

## Изменения относительно 1.5.0

- TV-интерфейс: строки всех групп, названия подписок, навигация пультом и исправленная вертикальная touch/fling-прокрутка в портретном режиме на смартфоне. Выбор группы сам по себе не меняет VPN-профиль.
- Обновления приложения: стабильный и тестовый каналы, загрузка/докачка APK, проверка целостности, package, версии и постоянной подписи перед системным установщиком Android. Установка требует подтверждения пользователя; смена канала не разрешает downgrade.
- Диагностика: раздельные результаты обновления подписки и проверки подключения, понятные коды ошибок, прогресс/отмена повторной проверки и безопасная локальная сводка. Исправлена гонка, вызывавшая ложное состояние занятости после завершения проверки.
- LAN: явный поиск локальных SOCKS5/HTTP listeners в доверенной физической сети и добавление/ручное обновление профиля текущего шлюза на порту 10808. Нет фонового сканирования, автосохранения или автоподключения.
- Сохранены Phone/TV, профили и группы, ручные редакторы, подписки, маршрутизация, QR и локальный браузерный обмен конфигурацией. Добавлены проверки воспроизводимой подготовки исходников и F-Droid-варианта без удаления функций.
- Документация, RU/EN-сайт и материалы передачи разработки хранятся вместе с кодом; новые агенты начинают с `AGENTS.md`.

## Установка и обновление

Выберите ARM64, ARM32 или universal APK по фактическому `apk-manifest.json`. Оба интерфейса входят в одно приложение. Package — `com.tunxbox.app`, постоянная подпись сохраняется. Для версии 1.6.0 ожидаемый stable versionCode — **48 999 999**, выше совместимых RC серии 48.

Перед обновлением сохраните резервную копию конфигурации. Обновление поверх приложения с тем же package и сертификатом не требует удаления; APK с другим ключом, включая отдельно подписанную сборку магазина, несовместим для такого обновления. Проверка сертификата не отключается. Фактические commit, versionCode, ABI, signer и SHA256 каждого опубликованного APK указаны в release manifest.

## Проверки и границы

На этапе подготовки rc.158 владелец подтвердил успешное обновление смартфона и предварительно нормальную портретную прокрутку. Модель/Android/ABI не сообщены; это не приёмка всех устройств, мыши, пульта или всех путей установки. Подтверждённые CI-результаты и незакрытые проверки перечислены в [handoff](../agent-handoff.md); результаты предыдущего коммита не заменяют проверку итогового release SHA.

- Нестабильность Hysteria2 и отдельные TLS/timeout-сценарии остаются предметом расследования: issues #6 и #10. Зелёный статус одного URL-теста не доказывает работоспособность всех сайтов, UDP или скорость.
- XHTTP, Xray и sing-box-extended в этот набор возможностей не входят. Неподдерживаемый транспорт не подменяется молча на TCP. Автоматический failover и динамический gateway-host не заявляются.
- Локальный HTTP-обмен конфигурацией не шифрует данные: используйте только доверенную сеть. Не публикуйте подписки, ключи, приватные endpoints и необработанные диагностические логи.
- Подготовка F-Droid-сборки не означает публикацию в основном каталоге. Recipe остаётся disabled до разрешения юридических, build-server, каталоговых и signing/update требований; проверка подписи не ослабляется ради другого магазина.

Наличие этого файла — материал подготовки, а не доказательство публикации stable. Статус выпуска определяется GitHub Releases и проверенными артефактами точного release SHA.
