TunXBox 1.5.0

Первый стабильный выпуск TunXBox на принятом master после PR #1. TV/Phone клиент на базе GPL upstream NekoBox/SagerNet/sing-box; не сервис выдачи VPN-подписок.

Возможности

  • Выбор TV или смартфон перед открытием основного интерфейса; TV на телефоне поддерживает поворот.
  • Пульт: видимый фокус, постоянное добавление профиля, Connect первым, безопасные общие экраны/редакторы.
  • Профили/группы, подписки, все ручные редакторы, импорт URL/clipboard/file/QR.
  • Явные receive/send/scan QR направления; браузерный LAN импорт без установки приложения на телефоне; заметное подтверждение получения; полная копия группы с внутренними связями.
  • Статус и трафик, TCP/URL проверки, логи, переход на Home/YouTube; закрытие UI не отключает VPN.
  • Брендинг TunXBox, постоянная подпись и обновление поверх совместимых RC; полная документация/карта/roadmap.

Установка

Выберите ARM64, ARM32 либо universal. В каждом APK оба UI. Подпись и package сохраняются; стабильный versionCode выше rc.106, удаление compatible предыдущей версии не требуется. Старые временные ключи требуют отдельной backup/migration процедуры.

Границы

Новая discovery функциональность, автоматический failover и специальная Happ/Incy миграция в 1.5.0 НЕ входят. Emulator/JVM/browser проверки не гарантируют каждого OEM/ARM/provider. LAN HTTP не шифрует передачу — только доверенная сеть; обе стороны полного группового обмена должны поддерживать новый protocol. QR/подписки содержат секреты: не публикуйте их в issues.
